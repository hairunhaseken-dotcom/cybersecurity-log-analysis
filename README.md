
# Cybersecurity Log Analysis

## 1. Project Overview
This project demonstrates basic security log analysis using Python.
It uses fictional login records to identify repeated failed login attempts.

## 2. Project Objectives
- Understand basic login logs.
- Practise beginner-level Python programming.
- Count failed login attempts by IP address.
- Identify IP addresses with repeated failed logins.
- Recommend basic security improvements.

## 3. Tools Used
- Python 3
- GitHub
- Windows 11

## 4. Detection Method
The program counts failed login attempts for each IP address.
An IP address with three or more failed attempts is flagged for review.

This is a simple learning exercise, not a production-grade security detection system.

## 5. Files
- `sample_logs.txt` — fictional login records.
- `analyze_logs.py` — Python analysis program.

## 6. How to Run
Open a terminal in the project folder and run:

`python analyze_logs.py sample_logs.txt`

## 7. Learning Outcomes
This project helps me practise Python, text-file processing,
basic security monitoring, and technical documentation.

## 8. Future Improvements
